# PULSE — revised gym demo

Extract the archive and open index.html in a modern browser. Keep assets/, style.css and app.js alongside it. No installation, build, backend or internet is required.

This fictional gym concept follows the user's chosen black/orange fitness reference. All instructors, prices, class times, hours and availability are illustrative. No real location exists.

Booking forms validate locally and show a temporary sample confirmation. No reservation, payment, email or storage occurs. Use sample form details.

Interactions: programme detail dialogs, training filters, day selection, demo booking, FAQ disclosures, mobile menu, monthly/annual price comparison. Keyboard focus styles and reduced-motion support are included.

Image attribution and generation prompts: assets/CREDITS.md. Verification details: VERIFICATION.txt.
